# OpenWrt 设备身份门户 0.1.3

**正式发布日期：2026-11-16。** 这是首次公开发布；之前的本地开发历史已合并为单一初始提交，公开版本标签为 `v0.1.3`。

## 提供的功能

- 无密码自助设备归属登记、身份管理、免登记白名单、黑名单及按设备指定出口。
- 基础准入独立运行；可选 Mihomo 分流有期限的 MAC+IP 许可和具体故障提示。
- 双栈地址、在线证据、离线未识别历史、主机名保留与 IPv6 低 64 位辅助查找。
- 紧凑 LuCI 管理页，当前地址直显、历史渐进展开、完整只读详情、原操作确认与键盘支持。
- 默认保留流量卸载，也可要求关闭；不自动改动全机网络、DNS、主 uhttpd、代理或加速配置。

## 获取与安装

本次为**源码发布**，下载 [源码 ZIP](https://github.com/fevenor/openwrt-identity-portal/archive/refs/tags/v0.1.3.zip) 或 [TAR.GZ](https://github.com/fevenor/openwrt-identity-portal/archive/refs/tags/v0.1.3.tar.gz)，或将 OpenWrt feed 固定到 `v0.1.3`，再用与目标固件匹配的 SDK/构建树构建两个包。安装与配置见 [README](../../README.md)，Nikki/Mihomo 接入见 [降级出口专题](../Mihomo与Nikki.md)。

两个包的版本均为 0.1.3；构建修订号保留为基础包 r2、LuCI r4，避免已安装测试包被识别为版本回退。没有上传设备现场配置、原始恢复包或私有依赖适配二进制，不承诺跨固件直接安装兼容性。

## 验证与已知边界

- 59 项后端隔离回归和 36 项合成浏览器检查通过；已有实际设备安装及 Android/Windows 登记反馈。用户确认 Windows 门户打开快、按设备指定出口正常。
- 姓名是自助填写，不代表实名校验；MAC 可以仿冒，随机 MAC 可能产生新记录，IPv6 后缀不能作为授权凭据。
- 历史最多 512 台、每台 16 个 IPv6，15 分钟合并保存，异常断电可能丢失最近 15 分钟；不是完整接入审计。
- 软件/硬件卸载和快速转发可能使旧连接绕过拉黑、出口切换和许可到期；不保证故障瞬间零泄漏。
- 控制器就绪不等于 IPv4/IPv6 TCP/UDP 已全部透明接管；目标故障、驱动差异、重启/卸载和规模性能仍须在部署环境验收。

详见 [验证记录](../验证记录.md) 和 [维护与安全边界](../维护与安全边界.md)。首次配置默认关闭，变更前保留有线/串口恢复通道和私有备份。
