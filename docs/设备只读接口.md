# 设备资料只读接口

## 范围

0.1.4 候选新增 `ubus call portal telemetry`，供统计等下游查询中立设备资料。接口不写注册表、观察历史或权限，不修改准入、路由或代理配置；不对登记页面匿名开放。调用方使用已有受控 ubus 管理通道，ACL 仅授予读取。

一次请求复用统一无线／邻居／租约／观察历史快照；枚举登记设备与已观察 MAC 的并集，不限于受控 AP。常规快照不会为每个设备启动 ip 或 ubus 请求；接口未做人员授权判断，也不靠后缀推断设备身份。

当前候选在快照前对缺少NDP证据的IPv6源做有界补采。仅接纳原始连接方向、本机公网/64内且非本机、无标记的源地址；缺邻居时用绑定LAN的一秒ping触发解析，再读取邻居。每轮最多8项，首次等待300秒，失败间隔900秒、最多3次，状态最多256项，仅放运行目录。空候选不重置退避；并发请求通过已有flock跳过重复探测。该操作可能产生少量邻居请求和ICMP，资料接口仍不写登记、权限、历史或路由；邻居证据不产生授权或在线保证。

## 返回字段

- `schema_version`：接口结构版本，当前为 1；与门户软件版本分开。
- `portal_version`：门户软件版本；`observed_at`：本次读取 Unix 秒。
- `network`：观察网络接口名；`scope`：`registered-and-observed`。
- `devices`：设备数组，每项包含 MAC、身份 ID/姓名、设备标签/备注、主机名及来源、注册状态、在线状态/证据、首次/最近明确观察时间。
- `addresses`：当前读取的完整 IPv4/IPv6 地址证据，每项含地址、地址族、证据、读取秒、租约到期秒和 `historical:false`。有效租约及非 FAILED/INCOMPLETE 邻居可提供地址线索，**不因此认定在线**。
- `historical_addresses`：历史地址，与当前证据分开；含观察秒，IPv6 可含规范化后缀。时间为 0 代表无可靠观察时间，不造当前在线或自动归属。

`online_state` 为 `online`、`offline` 或 `unknown`；`online_evidence` 复用现行 wifi/lan/unknown/none 语义，详见 [设备观察与历史](设备观察与历史.md)。STALE 邻居和有效租约并不证明在线。多个设备声称同一地址时，下游必须保留冲突，不能强行选择某个 MAC。

## 下游使用边界

统计服务以完整地址和当前观测时间关联，持久保存流量发生时的身份；记录缺字段、地址冲突或过期应保留未知。当前接口是资料来源，不是可用于鉴权的身份凭据。姓名变更、临时地址或随机 MAC 变化不能将今天信息套用到全部旧流量。

当前不分页，枚举规模受已保存观察历史上限和注册表规模影响；接口上限并非已验证吞吐承诺。失败返回错误，不把空列表当成功全量并据此删除身份历史。

## 验证

0.1.4 接口新增只读、不泄漏控制器密钥、全设备并集、STALE/过期租约、ACL和注册入口隔离回归；历史原件不改写，每请求仅一次配置/无线快照，快照失败返回错误而非空设备成功列表。原64项及新增4项补采回归使用隔离命令验证，真实驱动和网络覆盖仍需现场核验；此前0.1.3准入/页面语义不改变。软件版本候选与公开发布状态见 [变更记录](../CHANGELOG.md)，不因现场可用就标记公开发布，也不据此承诺所有驱动、真实数据路径与故障组合均已验证。
