# 设备观察与历史

## 历史与准入独立

准入注册表是 `/etc/config/portal`，观察历史是 `/etc/portal/history.tsv`，运行期缓存位于 `/var/run/identity-portal/history.tsv`。只读 RPC 不写历史，也不创建身份或授予白名单。关联、断开、租约及邻居信息由独立观察器收集：hostapd 事件捕捉短访问，15 秒快照补采主机名和地址，并由 procd 恢复订阅。事件订阅不向 hostapd 返回准入裁决。

最多保存 512 个 MAC，优先保留最近确有在线/关联事件的设备；每台最多 16 个不同 IPv6 地址。运行期原子更新，每 900 秒（15 分钟）合并刷盘，正常停止主动保存。异常断电可能丢失最近 15 分钟，磁盘故障和观察器停止另行排查；这不是完整接入审计或断电零丢失协议。首次部署时已彻底消失的设备不能追溯。随机 MAC 变化会产生不同记录。

历史按 TSV 保存 MAC、首次实际观察秒、最近在线/无线事件秒、最后主机名、最后 IPv4、最后明确接入方式、IPv6 与其观察秒。时间为 Unix 秒。仅由旧租约或旧邻居发现的离线条目，首次与最近时间可以为 0，表示没有可靠时间证据，不伪造“此刻刚连接”。持久文件权限 0600，并加入 sysupgrade 保留清单；备份也需按敏感资料处理。

## 在线与地址口径

- `wifi`：受控 AP 当前关联，显式未关联的条目不算在线。
- `lan`：桥转发表显示非受控无线端口、非本地 MAC、30 秒内的活动。它是近期二层活动证据，不承诺拔线瞬间感知；条件不满足时不因租约继续在线。
- `unknown`：AP 查询失败，或只有 REACHABLE 邻居但无法确认接入端口，界面显示“状态未确认”。
- 空接入方式：没有当前在线证据，显示离线。STALE 邻居和未过期租约单独不构成在线证据。

主地址显示优先有效 DHCP 租约，再按当前邻居证据选择普通 IPv4，不让 169.254/16 压过正常地址。离线时显示历史地址并明确标注。连接撤销仍使用独立地址全集，不因展示规则减少尽力清理范围。主机名读取租约，租约消失后回退历史，标注来源。关联时长在 hostapd 未提供时从单次 iw station dump 补取，未知时不造数据。

## IPv6 后缀及冲突

“IPv6 后缀”指规范化地址的低 64 位，以四组十六进制显示。例如 `2001:db8::10` 的后缀为 `0000:0000:0000:0010`。程序展开压缩零并统一大小写，不靠截取显示字符串或从 MAC 推算。当前规范化仅接受原生 IPv6，不接受 IPv4 尾部或带作用域后缀的混合字符串。

当前邻居提供的 IPv6↔MAC 映射优先。前缀变化但 MAC 相同的新地址直接出现在当前观察；历史保留旧地址和后缀。相同后缀在另一 MAC 的当前邻居中出现时，只输出带实际 MAC 的冲突候选，不自动合并、登记或加白，也不拼接前缀构造地址。链路本地后缀不用于猜测全局地址。

稳定隐私地址也可能随网络或前缀变化，临时地址会轮换，一个设备可有多个后缀；相同后缀并非身份凭据。未出现在邻居中的当前地址不能靠本功能证明存在。

## 查询与管理

`ubus call portal inventory` 一次读取注册表、无线/邻居/租约快照，返回 `devices`（登记设备）和 `unidentified`（未登记观察历史）。原有 `devices`、`unidentified` 查询保留。设备字段包含 `online_state`、`online_way`、`ip_source`、`hostname_source`、`first_observed`、`last_seen`、`last_way`、`ipv6`、`ipv6_history`、`ipv6_candidates`。历史 IPv6 时间 0 仍代表无可靠在线观察时间。

历史未登记设备离线时可通过已有管理员入口指派身份、加白或拉黑；执行后进入对应准入状态，不再当作未识别设备。移除授权记录 `forget` 删除准入信息但保留观察历史，仍可查看并按未登记规则处理。观察器可能再次发现仍在租约/邻居中的设备；容量淘汰不会删除独立的准入配置。

管理页按运行状态、在线未识别、身份、全量注册、历史未识别、审计、门户配置、卸载兼容策略排序。在线未识别与历史（离线/未确认）互斥分组，不重复请求后台；登记设备不重复进入未识别历史。MAC 下方显示厂商和随机 MAC 标记；在线状态、IPv4、当前 IPv6（每地址一行）合并展示；LuCI 将不重复当前的历史 IPv6 默认折叠为数量摘要，点开后显示每个历史地址。展开/收起状态在本页面自动刷新时保留，已退出快照的设备状态会清理；不保存浏览器偏好到设备配置。正常桌面宽度使用自适应表格，窄屏保留表格内横向滚动和表头，次要操作进入弹窗；页面隐藏时暂停前端刷新，不暂停后台观察。不得把前端显示缓存当作实际准入或即时在线证明。

## 查询开销

请求加载时建立 MAC→注册节名索引，IPv6 当前与历史地址批量规范化一次；JSON 构造只读取请求索引，不按地址启动规范化命令。缓存随每次配置加载重建，删除设备后不保留旧节名。观察器同样一次 awk 合并全部本轮观察，不逐个扫描离线历史。性能需以实际设备规模测量，512 的容量上限不代表在该规模下已完成延迟验收。

## 紧凑设备行交互

当前 IPv4 和全部当前 IPv6 直接可见，多地址时行高自然增加，不固定高度或截掉地址。历史地址默认数量摘要；“详情”或点击 MAC 查看完整地址/低 64 位、主机名、厂商、备注与完整时间。标签/备注在主表最多显示两行摘要，点击可查看原文。登记与最近时间使用月日时分摘要，完整年份/秒数可在悬浮提示和可点击详情中查看，手机不依赖悬浮。

原改身份和更多操作入口保留，只读信息查看不发送写入 RPC。原生 details/summary 支持键盘展开，有可见焦点，不通过 hover 自动隐藏当前信息。紧凑内边距只作用于本门户注册表，不修改其他 LuCI 页面或系统主题。
