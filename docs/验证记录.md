# 0.1.3 验证记录

本记录说明正式发布 0.1.3 的实际验证范围，不表示所有 OpenWrt 设备、AP 驱动、Nikki 版本或故障组合均通过生产验收。发布说明见 [0.1.3](发布说明/0.1.3.md)。原始现场证据包含敏感资料，不进入公共仓库。

## 按部署环境仍需验证

- 实际 IPv4/IPv6 TCP/UDP、目标出口不可用、Mihomo 停止/重启、同步终止、地址变化和旧连接撤销。
- 软件/硬件卸载或其他快速转发可能绕过门户链；默认允许卸载，不保证旧连接立即停止或故障瞬间零泄漏。严格模式也要求确认系统开关已真正应用。
- 各驱动的同 AP 隔离、随机 MAC、睡眠唤醒、无线持久禁连及解封、整机重启时地址/文件/服务顺序。
- 一般固件的标准依赖安装、版本匹配、完整升级/卸载、Nikki 预检与正式进程环境、订阅重建后的优先级。
- 低端设备吞吐量、高峰资源占用、512 台规模的查询延迟及断电丢失窗口；没有用容量上限冒充性能或审计完整性保证。

以上是正式版公开说明的使用边界。部署前在独立管理通道下执行 [实机验收](维护与安全边界.md#实机验收)，并按 [降级出口专题](Mihomo与Nikki.md) 核对实际透明接管和故障行为。
